## Under Active Development
liefOS (pronounced: layf-Oh-Es, stylized with lowercase "I' on the first letter. Short for Liejan's Fluid Operating System (lie - Liejan, f - Fluid + OS), quite complicated isn't it.) is a virtual simulated mobile operating system for desktop made using JavaScript, Node.js, and other web technologies. There's really no goal of liefOS here. It's a project I, Liejan, made for fun to fulfill my dreams of making my own operating system and designing it easily. liefOS was made for fun and to pass the time but eventually became my hobby and passion.
